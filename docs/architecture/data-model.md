# Data model

Current implementation (`20261108_0001` through `20261127_0014` linear Alembic chain):
- **Identity & access (`0001`–`0003`)**: `users` (`auth_epoch` invalidates old sessions on password reset; optional `display_name`), one-time `auth_tokens`, revocable `auth_sessions`, and `audit_events` (`user_id` nullable `SET NULL` on user delete, `action`, `created_at`, and since `20261127_0012` a nullable indexed `resource_id` holding the affected project ID for `project.created` / `project.updated` (#86) — never stores names, descriptions, emails, tokens, API keys, or passwords).
- **Projects & inputs (`0002`, `0004`, `0005`)**: `projects`, immutable `project_history` revisions, `sources` + immutable `source_versions` (SHA-256), and `datasets` + immutable `dataset_versions` (SHA-256).
- **AI configs, prompts & experiments (`0006`–`0008`)**: AES-256-GCM encrypted `provider_credentials` (`20261125_0006`), `prompt_templates` + immutable `prompt_versions` (`20261125_0007`, default `L1`–`L5` slots remain `UNAPPROVED` per SRS `TBD-04`), and `experiments` + append-only `experiment_snapshots` / `experiment_snapshot_runs` (`20261125_0008`).
- **Generation queue (`20261126_0009`)**: `generation_jobs` (`UNIQUE(project_id, request_id)` idempotency, `QUEUED | RUNNING | COMPLETED | FAILED | CANCELLED`) and `generation_runs` (`UNIQUE(job_id, ordinal)`, `QUEUED | RUNNING | COMPLETED | FAILED | TIMEOUT | CANCELLED`, redacted `.py` artifact relative path + `artifact_sha256` + sanitized `error_info`). Since `20261127_0013` (#39–#41): `generation_runs.response_metadata` (safe call metadata, JSON), `parsed_code` (extracted pytest module), `validation` (per-stage JSON, `pytest-module/v1`) and `generation_jobs.error_summary` (provider pause details).
- **Evaluation metrics & rubric (`20261126_0010`)**: `metric_records` (`UNIQUE(run_id, metric_name)`, `state` in `MEASURED | N/A | FAILED | TIMEOUT` preserving finite `0.0` distinct from `None`, `source_sha256`, structured `details`) and `assertion_reviews` (`UNIQUE(run_id, assertion_id)`, human rubric labels `EFFECTIVE | WEAK | TRIVIAL | INCORRECT | N/A`).
- **Sandbox executions (`20261127_0014`, #45-#49)**: `executions` (owner via `project_id`; `generation_run_id` SET NULL; status `QUEUED | PENDING | RUNNING | CANCELLING | CANCELLED | COMPLETED | FAILED | TIMEOUT | BLOCKED`; per-status case counts; JSON `cases`, safe `logs` (1 MiB cap), `oracle` (FR-EVL-002 provenance), `sandbox_policy`, `error_info`; source/dataset/artifact SHA-256). No generated code is executed while the launcher is disabled.
- **Reporting & audit (`20261126_0011`)**: `report_runs` standalone/evaluated run summaries unified alongside `generation_runs` + `metric_records` + `assertion_reviews`. On-disk artifacts reside strictly under `settings.artifact_dir/<project_id>/...` with anti-symlink + `is_relative_to` traversal guards and SHA-256 integrity verification (`IntegrityService` / `BackupService`, which strictly omits `provider_credentials`).

Use foreign keys and `404` owner checks across all project-scoped resources; frozen snapshots and versioned inputs remain immutable against SRS v1.2.
